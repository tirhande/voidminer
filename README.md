# VOIDMINER

캐서 만들고, 더 좋은 것을 캔다.

우주 소행성대에서 광물을 캐고, 거점으로 돌아가 제련하고, 합금으로 더 좋은 장비를 만들어 더 좋은 광물을 캐는 웹 3D 게임이다.

**[플레이하기](https://tirhande.github.io/voidminer/)** — 브라우저에서 바로 돌아간다. 설치도 로그인도 없다.

---

## 어떤 게임인가

```
소행성 채굴 → 파편 견인 회수 → 화물칸 적재 → 거점 도킹 → 하역
→ 제련(광석 → 주괴) → 합금(짝인 주괴 둘 → 합금) → 레이저 강화 · 제작
→ 상위 광물 해금 → 다른 항성계로 워프 → 반복
```

한 바퀴가 곧 게임이다. 처음 11단계는 화면 위 안내가 이끌어주므로 따라가면 된다.

| 항목 | 내용 |
|---|---|
| 광물 | 8종. 구리 · 주석 / 철 · 니켈 / 티타늄 · 알루미늄 / 이리듐 · 백금 |
| 합금 | 4종. 짝인 두 주괴를 합쳐 만든다 |
| 장비 등급 | 채굴 레이저 T1~T8. 등급 재료가 주괴와 합금으로 번갈아 놓인다 |
| 잠금 | 등급과 강화 수준 두 값이 함께 잠근다. 강화가 짝인 부광물을 열고, 그 짝으로 합금을 만들어 다음 등급으로 간다 |
| 항성계 | 5개. 나오는 광물이 다르다. 레이저 T2부터 워프가 열린다 |
| 소행성 | 크기가 곧 광물 등급의 단서다. 작은 것이 구리, 가장 큰 것이 이리듐이다 |

실패로 끝나는 조건은 없다. 사망 · 연료 · 적이 없다. 한 판의 끝은 안내 11단계를 마치는 시점이고, 그 뒤로도 T8까지 이어진다.

## 조작

| 구분 | 키 | 동작 |
|---|---|---|
| 비행 | W / S | 전진 · 후진 |
| 비행 | A / D | 좌우 이동 |
| 비행 | Space / C | 상승 · 하강 |
| 비행 | Q / E | 좌우 회전 |
| 비행 | 마우스 | 기수 방향 |
| 비행 | Shift | 부스트 |
| 비행 | X | 관성 제동 |
| 채집 | 좌클릭 | 채굴 레이저 |
| 채집 | 우클릭 | 견인빔 |
| 거점 | F | 도킹 · 도킹 해제 |
| 그 밖 | Tab | 화물칸 |
| 그 밖 | H | 조작법 |
| 그 밖 | Esc | 조종 해제 |

비행은 뉴턴식이다. 추력을 놓아도 속도가 유지되고 역추력이나 관성 제동으로만 줄어든다.

진행 상황은 브라우저에 자동 저장된다. 시작 화면의 버튼으로 지운다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

Node.js 22 이상이 필요하다.

| 스크립트 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사를 거쳐 배포용 빌드 |
| `npm test` | 테스트 |
| `npm run measure` | 게임을 켜지 않고 균형 수치를 계산한다 |

## 구조

```
src/
  main.ts            프레임 루프. 여기서만 다른 부품을 엮는다
  constants.ts       모든 조절값. 게임의 느낌을 바꾸려면 여기부터 본다
  palette.ts         색과 빛
  game/              게임 규칙. 화면과 무관한 것
  rendering/         화면 만들기. 규칙과 무관한 것
scripts/             빌드와 측정 도구
public/models/       3D 에셋
```

`game/` 은 three.js 없이도 뜻이 통한다. 규칙이 렌더링에 얽히면 규칙만 따로 시험할 수 없다. 테스트 대부분이 화면 없이 돈다.

모델이 없어도 게임은 돌아간다. 없으면 절차 생성 형상으로 대체된다.
